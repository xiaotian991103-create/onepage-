# Reference-case routing library

This public skill contains a text-only catalog of reusable OnePage structures. It intentionally does not bundle third-party case images. Use the catalog to classify user-provided references and to choose a layout family; it is not itself an ImageGen visual input.

## Selection rules

- Select one layout family and one compatible surface/style family.
- Prefer no more than one user-provided style or layout case in a text-heavy generation call.
- Omit style references when the brand identity and the approved visual system already define the direction.
- Never copy a reference's brand, copy, data, PR number, date, watermark, creator identity, or product.
- Use a vertical portfolio for module analysis only; never use the entire portfolio as a 16:9 layout anchor.

## Reusable layout families

### Three-column closure

Strategy | content/method | result. Use for cases with complete evidence and several strong KPIs. Keep the KPI area subordinate when the evidence is thin.

### Campaign timeline

Result | strategy | milestones | recap. Use for short campaigns, event launches, and rapid delivery. Keep milestone labels short and legible.

### Formula matrix

Formula | audience/content matrix | proof | validation. Use when the central value is a reusable content method. Make every proof item visibly support one formula component.

### Model validation

Method model | lifecycle or stage behavior | proof by stage | KPI dock. Use for investment logic and repeatable operating mechanisms. Do not invent trend shapes or stage ratios.

### Brand-color battlecard

Product-led header | three strategy pillars | proof strip | timeline | KPI footer. Use for FMCG, beauty, and brand-node projects. Derive the palette only from approved brand cues.

### Dark event spectrum

Use only when the brand or event genuinely supports dark high-contrast art direction. Reduce copy more aggressively than on light backgrounds and keep body text contrast high.

## Density limit for ImageGen

Borrow the structure and evidence binding, not the reference cases' text density. Target:

- one conclusion headline;
- three primary modules;
- three to five core indicators;
- three to six proof visuals;
- no more than two short lines per card;
- no decorative microcopy.
